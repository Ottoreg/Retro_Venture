# Données de contenu

Le contenu du jeu est décrit par des fichiers de données, éditables sans recompiler et validés par
schéma en intégration continue (voir [GDD § 16.3](../docs/GDD.md#163-contenu-piloté-par-les-données)
et les exemples en [annexe du GDD](../docs/GDD.md#20-annexes--formats-de-données)).

Organisation prévue :

```
data/
├── races/        ├── monstres/     ├── recettes/
├── voies/        ├── objets/       ├── quetes/
├── sorts/        ├── butin/        └── cartes/
```
