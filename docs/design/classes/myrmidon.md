# Myrmidon — Acier / Givre

**État** : pistes de l'auteur seulement (GDD § 4.3) ; rien de conçu ni de codé.

## Identité

- Rôle : tank. Famille corps à corps.
- Fantaisie : à écrire (parodie).
- Caractéristiques : Force (Acier pur) ; Perception (Givre pur) ; Vitalité.
- Base (PV, PA, PM, initiative) : à fixer.
- Principes : beaucoup de moyens d'arriver au contact, peu ou pas pour en sortir ; force les ennemis à
  l'attaquer (aura de provocation) ; pas de soutien (ne partage pas ses résistances, contrairement au Paladin).

## Passif de classe — à concevoir

Piste : la provocation (reprend le *Défi* envisagé pour le Guerrier).
