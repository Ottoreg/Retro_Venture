# Démoniste — Impie / Flamme

**État** : pistes de l'auteur seulement (GDD § 4.3) ; rien de conçu ni de codé. Classe la plus coûteuse à coder
(invocations).

## Identité

- Rôle : dégâts impies ou ardents. Famille distance.
- Fantaisie : à écrire (parodie).
- Caractéristiques : Agilité + Perception (Impie) ; Intelligence (Flamme).
- Base (PV, PA, PM, initiative) : à fixer.

## Passif de classe — à concevoir

Aucune piste. Doit servir l'armée de serviteurs comme l'embrasement du terrain.

## Voie Impie — serviteurs (0 / 10)

Pistes : invoque des serviteurs de plusieurs types (offensif, tank, soutien) qui forment son armée de démons.

- [ ] Signature (invocation)
- [ ] Dégâts de base pas cher
- [ ] Dégâts à distance ou en zone
- [ ] Gros coup cher
- [ ] Dégâts qui se combinent avec la signature
- [ ] Contrôle 1
- [ ] Contrôle 2
- [ ] Mobilité
- [ ] Défense
- [ ] Soutien (écart possible : plusieurs invocations comptées comme soutien ou défense)

## Voie Flamme — embrasement (0 / 10)

Pistes : chaque sort embrase les cases touchées (niveaux 1 à 3, puis calcinée à la 4e fois) ; chaque sort a
des variantes selon l'embrasement (exemple : *Mur de flammes* dure un tour par niveau ; sur une case
calcinée, il ne dure pas mais fait plus de dégâts dans sa zone).

- [ ] Signature (embrasement)
- [ ] Dégâts de base pas cher
- [ ] Dégâts à distance ou en zone
- [ ] Gros coup cher
- [ ] Dégâts qui se combinent avec la signature
- [ ] Contrôle 1 (Mur de flammes ?)
- [ ] Contrôle 2
- [ ] Mobilité
- [ ] Défense
- [ ] Soutien utile en solo

## 3e Voie (si validée)

Proposition : Ténèbres (démons d'ombre qui agrippent) ; contre-proposition : Lumière (Lucifer, flammes froides,
serviteurs lumineux qui aveuglent).

## Mécaniques à coder

Invocations (IA alliée, tour des serviteurs), état du terrain cumulable (embrasement, calciné).
